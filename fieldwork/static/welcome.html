Built-in engines

Use them in the console, from an AI agent, or on a file from the command line.

Discover

Census

Finds ownership, access, documentation and data-control gaps in the systems inventory, and writes the findings memo.

Integrate

Cortex authority check

Tests an agent's delegated permissions against expected scenarios. Flags write access with no human gate.

Test

Conformance

Pass rate by category against your bar. Any critical miss fails the stage.

Go-live

Command center

Reads the issue log and decides whether it's safe to stand down.

Adopt

Sendero

Is the friction a build problem or a training problem? A two-level outlier test on per-user data says which, and routes it.

Value

Value study

Did it work? The change against a comparison group, with a permutation test, and a refusal to call it on too little data.

Staffing

Threshold

Who can staff this deployment, requirement by requirement, with citations. Never infers what it can't see.

Your methodology, not ours

Deployments work alike enough to ship a strong default, and differently enough that every team needs to change it. Start from the template and change all of it.

  • White-label. Your product name, color and logo.
  • Your roles. Engagement managers, FDEs, consultants, customers. Access per deployment or workspace-wide.
  • Your stages. Exit criteria and up to four engines per stage.
  • Your fields and home screens. Per role.
  • Company sign-in. Okta, Microsoft Entra ID, Google Workspace, any OpenID Connect provider.
  • Enterprise-ready. Tenant isolation, encrypted secrets, Postgres, self-hostable.

Get started

Run an engine on a file in a minute, or run the whole platform.

pip install fieldwork
fieldwork engines                          # what's built in
fieldwork run census systems.csv           # readiness gaps and a findings memo, no server needed
fieldwork seed                             # demo workspace
FIELDWORK_DEMO=1 fieldwork serve           # console at http://127.0.0.1:8000

Connect an AI tool: create a personal access token in the console, then point your MCP client at /mcp with it.
